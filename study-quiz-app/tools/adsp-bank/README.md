# ADsP 문제은행 원본

앱에 내장된 ADsP 518문항의 원본과 생성 스크립트입니다.

| 파일 | 내용 |
|---|---|
| `q1.py` | 1과목 데이터 이해 (91문항) |
| `q2.py` | 2과목 데이터분석 기획 (78문항) |
| `q3a.py` | 3과목: 데이터 마트·결측·이상값, 통계 기초 |
| `q3b.py` | 3과목: 확률분포, 추정, 가설검정, 회귀, 다변량, 시계열 |
| `q3c.py` | 3과목: 정형 데이터 마이닝 |
| `q_tf.py` | 1·2·3과목 '옳은 것 / 옳지 않은 것' 문장형 98문항(PDF 강조 글씨 중심). 새 문제는 이 파일처럼 맨 뒤에 추가 |
| `glossary.py` | PDF의 `용어 : 설명` 줄을 자동으로 뽑아 용어집 만들기, 문장 속 용어 찾기 |
| `glossary_extra.py` | PDF에 `용어 : 설명` 형태로 없는 용어를 직접 적은 것(`EXTRA`), 문제별 지정 용어(`QT`), 별칭 |
| `choice_notes.py` | 오답 선지 설명(`n`)과 'PDF에 없는 선지' 표시(`nopdf`) |
| `make_bank.py` | 검증 → 용어정리·선지 설명 만들기 → 그림 자르기 → 앱용 JSON 출력 |

## 문제 작성 형식

```python
q("3-6", "엘보우",                                   # 단원, 개념(세트 안에서 유일)
  "그림은 Elbow Method 그래프이다. ... 최적의 K 개수는?", # 문제
  ["4", "2", "6", "9"],                               # 보기 4개, 첫 번째가 정답
  "Elbow Method는 경사가 완만해지는 지점을 ...",          # 해설(오답일 때 표시)
  "- 경사가 완만해지는 지점이 최적의 K 개수",               # PDF 원문 근거 문장(글자 그대로)
  img="elbow")                                        # 그림(선택)
```

문장형 문제(`q_tf.py`)는 문장 4개를 주고 종류를 정하면 문제·정답·보기 설명이 함께 만들어집니다.

```python
tf(3, "3-4", "OX 회귀 가정", "선형회귀분석의 가정", "옳은", [   # 과목, 단원, 개념, 주제, "옳은"/"옳지 않은"
    (T, "등분산성은 오차의 분산이 고르게 분포한다는 가정이다", "2. 등분산성 : 오차의 분산이 고르게 분포"),  # 옳은 문장, PDF 근거
    (F, "정규성은 오차가 서로 독립이라는 가정이다", "3. 정규성 : 오차가 정규분포의 특성을 지님",      # 틀린 문장, 바른 내용의 PDF 근거,
     "정규성은 오차가 정규분포의 특성을 지닌다는 가정이고, ..."),                                # 무엇이 틀렸는지
    ...
])
```

- 문제는 `"{주제}에 대한 설명으로 {옳은/옳지 않은} 것은?"`이 됩니다. 정답은 종류에 맞는 문장 하나입니다(옳은 → 옳은 문장 1개, 옳지 않은 → 틀린 문장 1개).
- 틀린 문장은 PDF의 **강조 글씨**(용어, 순서, 값)를 서로 바꿔 만듭니다. 정답이 아닌 보기의 설명은 "틀린 설명입니다. …" 또는 "옳은 설명입니다(PDF 내용과 같음)."으로 자동 등록되고, 근거는 PDF와 대조합니다.
- PDF에 근거가 없는 임의의 틀린 문장은 `(F, 문장, None, None)`으로 적으면 "PDF에 없는 선지입니다."로 표시됩니다.

## 검증 규칙 (`make_bank.py`)

- **문제 번호 유지:** 문제 ID(`adsp-NNN`)와 보기 순서는 파일 순서대로 정해지므로, 새 문제는 `SOURCES`의 맨 뒤 파일에 추가합니다. 중간에 넣으면 기존 기록과 이어 풀던 퀴즈가 다른 문제를 가리킵니다.
- **정답이 보이지 않게:** 문제 문장에 정답 단어(또는 정답만 가진 단어)를 넣지 않고, 암기법이 답을 알려 주지 않게 합니다.

- **근거 문장:** NFKC 정규화와 공백 제거 후 PDF 텍스트에 그대로 있어야 합니다. 8자 이상이어야 합니다.
- **보기:** 4개이며 서로 달라야 합니다.
- **개념:** 문제은행 전체에서 중복되면 안 됩니다.
- **비슷한 문제:** 글자 2-gram 유사도 0.6 이상이면 참고용으로 출력합니다(오류는 아님).

## 그림

`FIGURES`에 PDF 쪽 번호, 150dpi 기준 자르기 영역, 가릴 영역 `(x0, y0, x1, y1, 표시 글자)`가 있습니다.

- 칸 하나만 가리면 나머지 칸을 보고 소거법으로 답이 나오므로, 같은 종류의 칸은 **모두** `(가)(나)(다)…`로 가리고 문제에서 그중 하나를 묻습니다.
- 표시 글자가 `""`이면 흰색으로 지웁니다. 지운 자리에 그래프 선이 끊기면 `("line", x0, y0, x1, y1)`로 다시 그립니다.
- 표시 글자에 한글 글꼴(`fonts-wqy-zenhei`)이 필요합니다.

## 실행

```bash
cd study-quiz-app
npm run bank -- "/경로/ADsP 핵심정리.pdf"
```

문제를 바꿨다면 `src/lib/builtin.ts`의 `ADSP_BANK_VERSION`을 1 올리세요.

## 용어정리와 선지 설명

앱은 풀이 맨 밑에 **용어정리**를, 오답일 때 **내가 고른 선지 설명**을 보여 줍니다. 둘 다 `make_bank.py`가 문제마다 만들어 JSON에 넣습니다.

- **용어정리(`glossary`)**: 정답 보기 → 다른 보기 → 문제에 직접 지정한 용어(`QT`) → 문제 본문 순으로 PDF 용어를 찾아 최대 8개를 넣습니다.
  - 용어집은 PDF의 `용어 : 설명` 줄 약 390개를 자동 추출하고(`BLOCK`에 있는 예시 줄은 제외), `glossary_extra.py`의 직접 적은 용어를 더합니다.
  - 같은 용어가 여러 번 정의된 경우(예: KDD의 '평가'와 CRISP-DM의 '평가')는 문제 문맥과 가장 가까운 설명을 씁니다.
  - 두 글자 이하 말, 흔한 말(`GENERIC`), 두 글자 영문 약어는 보기 전체가 그 말일 때만 인정해 엉뚱한 매칭(예: CRISP-DM 속 DM)을 막습니다.
- **선지 설명(`choiceInfo`)**: 오답 보기마다 만들고 정답 보기는 `null`입니다. 우선순위는 아래와 같습니다.
  1. `choice_notes.py`에 직접 적은 설명(PDF 근거 문장 필수. `"="`는 그 문제의 근거 문장과 같다는 뜻)
  2. 보기가 용어이면 그 용어의 PDF 정의
  3. 순서만 바꾼 선지는 "PDF에 없는 순서입니다. PDF의 순서는 …"
  4. PDF에 없는 선지는 "PDF에 없는 선지입니다."(임의로 만든 선지는 설명을 지어내지 않음)
- **검증(실패하면 중단)**: 용어 설명과 선지 설명의 근거가 모두 PDF에 있어야 하고, 모든 오답 보기에 설명이 있어야 하며, 모든 문제에 용어정리가 1개 이상 있어야 합니다. `nopdf`로 표시한 긴 선지가 실제로 PDF에 있으면 오류입니다.
