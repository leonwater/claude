# 변경 이력

APK 버전 `1.0.N`의 N은 GitHub Actions 실행 번호입니다.

## 1.0.4 — 2026-10-25

- **풀이 팝업:** 답을 고르면 결과(정답/틀림, 정답 번호)와 **풀이 보기** · **다음 문제** 버튼만 보입니다. 풀이 보기를 누르면 풀이가 아래에서 팝업으로 열리고, 휴대폰 뒤로 가기를 누르면 팝업만 닫힙니다.
- **옳은 것 / 옳지 않은 것 문제 98개 추가(420 → 518문항):** PDF에서 주황(빨강) 글씨로 강조된 내용을 중심으로 만든 문장형 문제입니다. 틀린 문장은 강조된 용어·순서·값을 바꿔 만들었고, 고른 문장이 왜 틀렸는지(또는 옳은 설명인지)를 PDF 근거와 함께 보여 줍니다.
- **답이 쉽게 보이던 문제 수정:**
  - 그림에서 한 칸만 가려 나머지 칸으로 답을 알 수 있던 그림 10장을, 같은 종류의 칸을 모두 (가)(나)…로 가리도록 바꿨습니다(분석 유형, 빅데이터 분석 방법론, 분석 준비도·성숙도, 분석 수준, 오류표, 오분류표, 첨도, 박스플롯 경계값, Elbow).
  - 문제 문장에 정답 단어가 들어 있거나 암기법이 답을 알려 주던 문제 30여 개의 문장·보기를 고쳤습니다.
- 같은 용어는 PDF에서 강조된 표현을 우선 썼습니다.
- 2과목 문항 수 선택지를 10/20/26에서 10/20/30으로 바꿨습니다(97문항).
- 기존 420문항의 번호와 풀이 기록은 그대로 이어집니다.

## 1.0.3 — 2026-10-20

- **내가 고른 선지 설명:** 오답을 고르면 그 선지가 무엇인지(PDF의 정의, 또는 어느 개념의 식·값인지)를 보여 줍니다. 임의로 만든 선지는 "PDF에 없는 선지입니다."로만 표시합니다.
- **용어정리:** 풀이 맨 밑에 그 문제와 보기에 나온 PDF 용어와 설명을 보여 줍니다(문제당 최대 8개, 전부 PDF 원문과 대조).
- 풀이가 길어져도 **다음 문제** 버튼이 화면 아래에 떠 있어 스크롤 없이 넘길 수 있습니다.
- 문제은행 생성 도구에 용어 자동 추출·검증을 추가했습니다(`tools/adsp-bank/glossary*.py`, `choice_notes.py`).

## 1.0.2 — 2026-10-14

**ADsP 문제은행 내장**

- ADsP 1·2·3과목 핵심 정리 PDF로 만든 420문항을 앱에 넣었습니다. 그림 문제 37개와 그림 29장이 포함됩니다.
- 과목(1·2·3과목·종합)을 고른 뒤 과목별로 정한 문항 수(1과목 10/20/30, 2과목 10/20/26, 3과목·종합 10/25/50)로 출제합니다. 종합은 1:1:3 비율입니다.
- 진행 중인 퀴즈를 저장해, 앱을 다시 열면 같은 문제와 같은 보기 순서로 이어집니다. 끝내기를 눌러야 새 퀴즈를 시작할 수 있습니다.
- 오답을 고르면 정답 번호와 내용, 해설, 근거 문장을 보여 줍니다.
- 그림을 누르면 크게 볼 수 있습니다.

**고친 점**

- 결과 화면의 '처음으로'가 홈이 아니라 한 단계 전 화면으로 가던 문제
- 과목 전체를 돌 때 일부 문항이 빠질 수 있던 출제 순서(덜 푼 문제를 항상 먼저 출제하도록 변경)

## 1.0.1 — 2026-10-14

- Capacitor로 안드로이드 APK를 만들고, GitHub Actions에서 서명된 APK를 빌드해 Releases에 올리도록 했습니다.
- 백업 파일을 공유 창(드라이브, 카카오톡 등)으로 내보낼 수 있습니다.
- 문제 생성 중에 화면이 꺼지지 않게 했습니다.

## 웹 버전 (PWA)

- 파일(PDF·DOCX·TXT·MD) 업로드 후 원문을 그대로 추출하고, Claude API로 섹션별 문제은행을 만드는 기능을 넣었습니다(근거 문장 원문 대조, 중복 제거).
- 10/20/30/40문항 퀴즈와 오답노트(정답률 70% 초과 시 졸업), 오프라인 풀이, 백업/복원을 넣었습니다.
- 마지막 문제를 빨리 넘기면 결과에서 빠지던 문제를 고쳤습니다(답안 기록이 끝난 뒤에 채점 화면을 표시).
