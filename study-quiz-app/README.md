# 자료 퀴즈 (개인용)

파일을 올리면 원문 그대로를 근거로 객관식 문제를 만들어 주고, 틀린 문제는 오답노트로 관리하는 개인용 모바일 웹앱(PWA)입니다.
스토어에 배포하지 않고 혼자 쓰는 것을 전제로 합니다. 서버는 없고, 자료와 기록은 모두 내 기기의 브라우저에 저장됩니다.

## 기능

- **자료 읽기:** PDF(텍스트 PDF), DOCX, TXT, MD 파일을 여러 개 한 번에 올릴 수 있습니다. 파일당 100MB, 세트당 20개까지입니다.
  텍스트는 기기 안에서 글자 그대로 추출해 저장하며, 요약하거나 고치지 않습니다. 스캔(이미지) PDF는 지원하지 않습니다.
- **문제은행:** 섹션 분량에 비례해 섹션마다 최소 3문항씩, 기본 80문항을 미리 만듭니다.
  모든 문제는 정답 근거 문장이 원문에 글자 그대로 있어야 저장됩니다(공백 차이만 허용). 같은 개념이나 거의 같은 문장의 문제는 중복으로 걸러집니다.
- **퀴즈:** 10/20/30/40문항 중에서 고릅니다. 섹션 비율대로 고르게 출제하고, 덜 풀어본 문제를 먼저 냅니다.
  한 퀴즈에 같은 개념은 한 번만 나오며, 보기 순서는 매번 섞입니다.
- **오답노트:** 틀린 문제가 자동으로 등록되고 정답률(맞힌 수/시도 수)이 표시됩니다.
  정답률이 70%를 **넘으면**(>) 졸업합니다. 처음 틀린 문제는 3번 연속 맞히면 75%가 되어 졸업합니다.
- **오프라인:** 문제은행을 만든 뒤에는 인터넷 없이도 풀 수 있습니다(HTTPS로 열었을 때).
- **백업:** 설정 화면에서 전체 데이터를 JSON 파일로 내려받고 복원할 수 있습니다.

## 실행

```bash
npm install
npm run dev        # PC와 같은 Wi-Fi에 있는 휴대폰에서 표시된 Network 주소로 접속
npm test           # 단위 테스트
npm run build      # dist/ 폴더에 정적 파일 생성
```

### 안드로이드 앱(APK)으로 설치하기

`study-quiz-app/`이 바뀌어 푸시되면 GitHub Actions(`.github/workflows/android-apk.yml`)가 서명된 APK를 빌드해 **Releases**에 올립니다.

1. 휴대폰 브라우저로 저장소의 **Releases** 페이지를 열고, 최신 릴리스의 `studyquiz-1.0.N.apk`를 내려받습니다.
2. 다운로드한 파일을 엽니다. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켭니다.
3. 새 버전도 같은 방법으로 덮어 설치하면 됩니다. 서명 키(`android/app/studyquiz.keystore`)가 같아 자료가 유지됩니다.
   앱을 **삭제**하면 자료도 지워지니, 그 전에 설정 → 백업 파일 내보내기를 하세요.

앱 빌드에서는 서비스 워커를 끕니다(앱 파일이 이미 기기에 있음). 백업은 공유 창(드라이브, 카카오톡 나에게 보내기 등)으로 내보냅니다.

### 휴대폰에 설치하기 (Netlify)

저장소 루트의 `netlify.toml`에 빌드 설정이 들어 있어, 저장소만 연결하면 됩니다.

1. netlify.com에 GitHub 계정으로 가입 → **Add new project → Import an existing project → GitHub** → 이 저장소 선택
2. **Branch to deploy**에서 앱 코드가 있는 브랜치 선택 → **Deploy**
3. 발급된 `https://….netlify.app` 주소를 휴대폰에서 열고 홈 화면에 추가
   - iPhone: Safari → 공유 → 홈 화면에 추가
   - Android: Chrome → ⋮ → 앱 설치(홈 화면에 추가)
4. **홈 화면 아이콘으로 연 앱에서** API 키를 입력합니다(iPhone은 Safari 탭과 홈 화면 앱의 저장소가 따로입니다)

API 키는 빌드에 들어가지 않고, 자료는 각 기기에만 저장됩니다. 브랜치에 푸시하면 자동으로 다시 배포됩니다.

## Claude API

- 설정 화면에서 API 키를 입력합니다. 키는 기기의 브라우저에만 저장되고 Anthropic API로만 전송됩니다.
  Claude Console에서 월 사용 한도를 걸어 두세요.
- 모델은 Claude Opus 5.5(기본), Sonnet 5.5, Haiku 5.5 중에서 고릅니다. 생성 전에는 추정 비용을, 생성 후에는 실제 비용을 보여줍니다.
- 요청에는 structured output(JSON 스키마)과 원문 블록 prompt caching을 사용합니다.
  Opus/Sonnet에서는 모델이 출제를 거절하면 다른 모델로 대신 처리하도록 `fallbacks: "default"`를 켜 둡니다.

## 구조

```
src/lib/parse.ts      파일 → 문단 (pdf.js, mammoth)
src/lib/sections.ts   문단 → 섹션(제목/길이 기준)
src/lib/allocate.ts   비율 배분
src/lib/claude.ts     문제 생성 요청
src/lib/verify.ts     근거 문장·형식·중복 검증, 보기 섞기
src/lib/generate.ts   문제은행 채우기(중단 후 이어서 가능)
src/lib/quiz.ts       퀴즈 구성
src/lib/wrongNote.ts  오답노트 정답률·졸업 규칙
src/screens/          화면
```
